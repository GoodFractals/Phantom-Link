DECISIONS
- One firmware source, two build targets: phantom_link_ap (IS_AP=1) and
  phantom_link_sta (IS_AP=0).
- IS_AP determines only the Wi-Fi role. Both boards run the full UI and input.
- AP role: Barebones; STA role: Jank Box 5000. Confirmed before flashing.
- Codec: 3-digit Base-6 over 49 codes (48 glyphs + space), implemented.
- STA address: static 192.168.4.2/24 for the PoC because the AP has no DHCP
  server. Replace with DHCP or a configurable address before product use.
- Do not add Speck or MAC-layer SFO until T1-T7, T9, T10 pass on hardware.
