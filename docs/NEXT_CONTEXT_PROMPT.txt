HARDWARE
- 2x Raspberry Pi Pico 2 W (RP2350 + CYW43439)
- Both boards carry the identical BOM:
  - Inland 1.3" SH1106 128x64 SPI OLED: CLK GP18, MOSI GP19, RES GP20,
    DC GP16, CS GP17, +2 column offset
  - PSP-1000 joystick: X GP26/ADC0, Y GP27/ADC1
  - SELECT GP14, DELETE GP15, BACK GP12, all to GND with internal pull-ups
- AP board: Barebones (host, Clyde)
- STA board: Jank Box 5000 (client, Bonnie)
- Each rig runs from a 2000 mAh USB power bank zip-tied under the breadboard.
  No enclosure, no battery-sense hardware; the pack LEDs are the gauge.

CURRENT STATE
- One firmware/main.c, two targets. IS_AP selects only the Wi-Fi role; the
  OLED, ADC joystick, buttons, input polling, codec, parser, and render path
  are unconditional in both builds.
- Wi-Fi bring-up is non-blocking. Static STA address 192.168.4.2/24 because
  the SDK 2.3.1 AP build has no DHCP server (CYW43_NETUTILS=0).
- Numeric-page HUD: four RSSI bars on the STA, link square beside LINK. The
  AP has no per-client RSSI, so its signal cell stays empty until the STA
  relays a reading. BAT: is reserved and has no sense path.
- 49-code 3-digit Base-6 character encoding inside typed frames: 18-byte
  header, CRC32 auth field, HELLO/HELLO_ACK/PING/PONG/DATA, FINAL ends a
  message. Peer learning, 1 s heartbeat, 3 s timeout, non-blocking TX,
  boot splash.
- Session layer: hardware-random session ID per handshake (get_rand_32),
  per-direction sequence from 0, 32-bit sliding replay window, duplicate and
  stale counters, sequence-gap message invalidation, 30 s SESSION stats line.
- The token build reached LINK UP and sent typed messages on hardware. The
  framed/session build (tickets 03-05) has not been flashed; the full T2-T12
  matrix and the HUD build still need a hardware run.

DECISIONS (see docs/adr/)
- Speck128/128 CTR + CMAC, behind a cipher-agnostic interface with an AEAD slot.
- SFO is application-layer and telemetry-only. No MAC-layer SFO is possible
  with cyw43; do not claim it.
- No battery-sense hardware and no enclosure.
- Strictly two-party. Membership is physical possession; group support is a
  non-goal, not a missing feature.
