The black-box experiment

Before there was a cipher, there was one question: can two Pico 2 W boards, driven only through a closed Wi-Fi firmware blob and a public SDK, find each other and move a message at all?

The encryption was the cherry on top. The experiment was the transport. Every crypto claim in the other brag sheet assumes the answer to this one was yes — and in the early days it was not at all obvious that it would be.

Rule of the house: this page brags about the thing we proved first. The radio was opaque, the SDK was incomplete, and nothing about "two boards talking" was guaranteed. No NDA claims, no firmware hacks, no magic — just a black box driven through its public interfaces until it moved a byte.

0. What "black box" meant in practice

The CYW43439 firmware is a proprietary binary blob shipped as precompiled headers in the Pico SDK (for example lib/cyw43-driver/firmware/w43439A0_7_95_49_00_combined.h, about 1.4 MB). We never patched it, reverse-engineered it, or injected raw 802.11 frames. We had normal STA/AP interfaces, lwIP sockets, and a handful of GPIO calls — and nothing else.

That is the constraint that makes the experiment interesting: we had to build a reliable, honest link without being able to see or change the thing carrying it. ADR 0002 records the consequence directly — true StegoFrameOrder needs monitor mode and raw frame injection, which this hardware does not expose through cyw43. So the side channel had to move up a layer. We did not pretend otherwise.

1. The questions we had to answer first

Q1 Can an AP even come up without a DHCP server?

Proven SDK 2.3.1's AP build has no DHCP server. The STA uses a fixed address 192.168.4.2/24 with gateway 192.168.4.1, and the pair still links. Early two-board logs show the STA waiting for an IP; the static-address change fixed it.

Brag We read the actual SDK behaviour instead of assuming a router existed, then made the link work with two addresses and no infrastructure at all.

Q2 Can the UI stay alive while Wi-Fi associates?

Proven Wi-Fi bring-up is non-blocking; OLED, input, codec and render path run unconditionally. IS_AP selects only the Wi-Fi role — both boards type, send, receive and render.

Brag The radio never owned the main loop. A board can be associate-ing, drawing a menu, and reading the joystick at the same time — on a part with roughly 8 KB of stack.

Q3 How do two strangers find each other?

Proven The AP learns the peer address from the received datagram; the STA initiates HELLO / HELLO_ACK. Peer learning and static addressing made the first real LINK UP possible without any configuration exchange outside UDP.

Brag No handshake server, no discovery daemon, no broadcast magic. The packet itself told us who was talking.

Q4 Is the link state true, or just a happy LED?

Proven T2 visual check confirmed the HUD reflects the real session state; ticket 09 passed T2–T12 on build e4fadca7 with replay rejected and both serial logs archived.

Brag When the screen said LINK, there was actually a link. That sounds trivial until you have watched a radio lie to a UI.

Q5 Can a 21-glyph message survive a datagram path?

Proven Tickets 06/07: 10% induced loss still delivers a 21-glyph message exactly once in both directions; sequence numbers, ACKs, bounded retransmit and a 64-deep TX queue; DELETE aborts cleanly.

Brag We built reliability on top of UDP — no TCP, no broker, no retransmission service — and proved it under induced loss.

2. The moment the experiment turned

First came a boot banner on both boards before any Wi-Fi line (ticket 02, with a hash tying the log to main.c). Then came the first link=UP on both sides with a shared session. Then a 21-glyph round-trip. At that point the black box was no longer a mystery — it was a transport we could build on.

Only then did the cherry go on: tickets 10–14 added Speck, KDF, CMAC and hardware crypto acceptance; 31–34 added ephemeral X25519, per-frame ratchets, ECDH-masked headers and an AEAD opt-in. None of that would have meant anything if the radio had refused to carry a reliable frame in the first place.

3. The sentence to say out loud

Say “I started with a $5 radio whose firmware I could not inspect, proved a reliable two-board transport using only public SDK APIs, and only then layered forward-secret encryption on top. The interesting problem was the black box; the crypto was the reward for solving it.”

That is a systems-engineering story, not a library-usage story. It says you can work at the boundary where hardware, a closed vendor blob, and your own protocol meet — and that you know which part was actually hard.

4. What this does not claim

  • Not an NDA claim: the firmware is proprietary, but we are not a party to any agreement about it.
  • Not a firmware hack: no patching, no reverse engineering, no raw 802.11 injection.
  • Not MAC-layer SFO or covertness: the CYW43 only exposes normal STA/AP interfaces; our traffic shaping is application-layer (ADR 0002, tickets 15/16/29).
  • Not untethered yet: this experiment used USB-connected boards; power-rig gates are still open.
