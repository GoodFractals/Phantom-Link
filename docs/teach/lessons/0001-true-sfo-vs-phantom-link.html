True SFO vs Phantom Link's variant

Read time: 6 minutes. One win: you can explain why our SFO is telemetry, not covert payload delivery.

1. What textbook SFO actually does

StegoFrameOrder (Sawicki et al., 2021) hides data in the order of IEEE 802.11 MAC frames. It exploits the non-deterministic frame ordering that normal wireless stacks produce, so an observer sees ordinary traffic while the sequence itself carries bits. This needs low-level access: monitor mode and raw frame injection at the MAC layer.

Primary source: Sawicki et al., 2021

2. Why we cannot do that here

The Pico 2 W uses the CYW43439 through the cyw43 driver. It exposes a normal AP or STA interface — no monitor mode, no raw 802.11 frame injection ([[RESOURCES.md]]: ADR 0002). The chip is a closed black box. So true SFO is physically unavailable, not merely difficult.

Rule: never claim MAC-layer SFO or raw-frame access. ADR 0002 locks this.

3. Our tailored approach: order at the application layer

We move the same idea one layer up, into UDP packets:

  • One burst = four small datagrams, each tagged with its index 0–3.
  • The receiver observes their arrival order. That permutation encodes one nibble (4 bits).
  • There are 24 possible orders of four items. We use 16 for nibbles 0–15 and reject the other 8.
  • A CRC8 over context + nibble detects corruption; three repeated bursts are resolved by majority decode.

See firmware/proto/proto_sfo.c and ticket 15 ([[RESOURCES.md]]).

4. The critical boundary: telemetry only

Our SFO channel carries no user message content. It reports channel quality: good/total bursts, bits per second, reorder rate, and a SFO degraded state. If every burst fails, messages still deliver normally; the only consequence is a log line and a counter. This is the heart of ticket 16, which we are about to implement test-first.

A failed burst is not a message failure. No SFO failure may block, delay, or reorder a user message.

5. Do not confuse SFO with LPI shaping

LayerWhat it changesWhy
SFOArrival order of 4 datagramsTelemetry channel (this lesson)
LPI shapingFixed frame length, random padding, decoy traffic, jitter, masked headerMake traffic less bursty/less obvious (ticket 29)
Link cryptoPayload ciphertext + CMAC + key confirmationConfidentiality and authentication (tickets 10–12)

They are separate mechanisms. A decoy is not an SFO burst; a masked header is not a covert payload.

6. Retrieval practice

Q1. True SFO requires:

A. RAW FRAME INJECTION MODE
B. NORMAL WIFI STATION MODE

A — monitor mode and raw 802.11 frames; the CYW43439 cannot do this.

Q2. One Phantom Link burst encodes:

A. FOUR BITS PER BURST
B. FOUR BYTES PER BURST

A — one nibble, from the arrival order of four datagrams.

Q3. If SFO fails completely:

A. MESSAGES STILL ARRIVE
B. MESSAGES ARE BLOCKED

A — degraded mode logs and counts; delivery is unaffected.
